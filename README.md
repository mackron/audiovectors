This repository contains a database of audio test vectors.

Files are in the [vectors](vectors) folder, with a sub-folder for each type. The directory structure will give you an idea of where the files originate.

I've collected these files from multiple sources, some of which I found by simply searching the internet, whereas some were sent to me through bug reports, and others I just generated with a tool. Where applicable, I've included readme files in the relevant folders with links back to the original source. There are no commercially licensed files here to my knowledge. If by chance some of these files belong to you and you'd rather they not be included in this repository by all means reach out and I'll remove them.

Anything in a "generated/" folder is a synthetic test generated by the [generate.sh](tools/generate.sh) script. Consider these public domain. You can freely use these however you like.

There are no rules regarding how to use these test files. It's just a collection of audio data and nothing more. It includes both valid and invalid files, and not everything is just a plain audio file. The Opus test vectors, for example, include both the raw Opus bitstream (not encapsulated), with an associated decoded representation for comparison purposes. Most other files are just regular standalone audio files. It's up to the consumer of this database to decide how they want to use each file.
